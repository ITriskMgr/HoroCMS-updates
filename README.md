# HoroCMS updates

This repository only publishes **signed update packages** for HoroCMS, a private, encrypted register for a fine-watch collection by Marc-André Léger ([www.leger.ca](https://www.leger.ca)). It contains no source code and no user data.

- Each release holds `latest.json` (version, notes, one download link and signature per platform) and the update packages for macOS and Windows.
- Installed copies of HoroCMS read `releases/latest/download/latest.json` and install an update only if its signature matches the release key built into the app.
- Releases are created automatically by the build of the (private) HoroCMS project.

---

Ce dépôt sert uniquement à publier les **mises à jour signées** de HoroCMS. Il ne contient ni code source ni donnée d’utilisateur. HoroCMS n’installe une mise à jour que si sa signature correspond à la clé de publication intégrée à l’application.
