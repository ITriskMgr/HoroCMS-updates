# HoroCMS — free beta for watch collectors

**HoroCMS** is a private, encrypted register for a watch collection, by Marc-André Léger ([www.leger.ca](https://www.leger.ca)). It runs on your own computer: no account, no cloud, and your collection never leaves it unless you choose to. It is free.

**Current version: beta 0.2.2** · [What's new](https://github.com/ITriskMgr/HoroCMS-updates/releases/latest)

## Download

| Your device | Download | Notes |
|---|---|---|
| Mac (Apple silicon or Intel, macOS 13 or later) | [HoroCMS-Mac.dmg](https://github.com/ITriskMgr/HoroCMS-updates/releases/latest/download/HoroCMS-Mac.dmg) | Not yet signed by Apple: see the installation guide for the one-time *Open Anyway* step. |
| Windows 10 or 11 (64-bit) | [HoroCMS-Windows-Setup.exe](https://github.com/ITriskMgr/HoroCMS-updates/releases/latest/download/HoroCMS-Windows-Setup.exe) | Not yet signed: choose *More info › Run anyway* once. |
| Android phone (Android 8 or later, 64-bit) | [HoroCMS-Android.apk](https://github.com/ITriskMgr/HoroCMS-updates/releases/latest/download/HoroCMS-Android.apk) | Optional companion: shows your collection on the phone. Install the computer version first. |
| iPhone | Coming later | The iPhone companion is not yet offered to the public. |

Once installed, HoroCMS tells you when a new version is available.

## Feedback

This is a beta and your feedback shapes it. In HoroCMS, open **Support** in the menu to send a suggestion, report a problem or ask a question.

HoroCMS is free. A small sponsor space may appear in the future to help cover the time it takes, but the intention is to keep it free.

## En français

**HoroCMS** est un registre privé et chiffré pour une collection de montres, par Marc-André Léger. Il fonctionne sur votre propre ordinateur : aucun compte, aucun nuage, et votre collection n’en sort jamais sans votre accord. Il est gratuit.

- **Mac** : [HoroCMS-Mac.dmg](https://github.com/ITriskMgr/HoroCMS-updates/releases/latest/download/HoroCMS-Mac.dmg) (pas encore signé par Apple : voir l’étape *Ouvrir quand même* du guide d’installation)
- **Windows** : [HoroCMS-Windows-Setup.exe](https://github.com/ITriskMgr/HoroCMS-updates/releases/latest/download/HoroCMS-Windows-Setup.exe) (choisissez *Informations complémentaires › Exécuter quand même* une fois)
- **Android** : [HoroCMS-Android.apk](https://github.com/ITriskMgr/HoroCMS-updates/releases/latest/download/HoroCMS-Android.apk) (application compagnon facultative)
- **iPhone** : à venir
- **Guide d’installation** : [en ligne](guides/GUIDE_INSTALLATION.md) · [PDF](https://github.com/ITriskMgr/HoroCMS-updates/releases/latest/download/HoroCMS-GUIDE_INSTALLATION.pdf)

Vos idées et signalements sont les bienvenus : dans HoroCMS, ouvrez **Soutien** dans le menu.

This repository holds no source code and no user data. Each release also carries the signed update packages and `latest.json` that installed copies of HoroCMS check; an update is installed only if its signature matches the release key built into the app.
